An image imported from `src/assets` is optimised at build — converted, resized
into a `srcset`, given its width and height so nothing shifts as it loads.
Files in `public/` are served as they are.

Each page keeps its images in its own folder —
`src/assets/pages/<page>/images/`, `graphics/` and `logos/`, with `home` for
`/` — and what more than one page uses goes in `src/assets/shared/`. Name
each file for what it shows: `team-workshop.jpg`, not `IMG_2034.jpg`.

| Variant       | For                                                    |
| ------------- | ------------------------------------------------------ |
| `full-width`  | images as wide as the screen or their column (default) |
| `constrained` | images up to their own width                           |
| `densities`   | small fixed-size images: logos, avatars — 1x and 2x    |

`alt` says what the image shows that the page needs — for a logo, the
company's name; for a chart or screenshot, what its text says. Leave it out
for a decorative one: `Img` renders `alt=""`, which screen readers skip. The image above
the fold — usually the hero — takes `loading="eager"` and
`fetchPriority="high"`; everything else stays lazy.
