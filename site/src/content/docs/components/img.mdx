An image imported from `src/assets` is optimised at build — converted, resized
into a `srcset`, given its width and height so nothing shifts as it loads.
Files in `public/` are served as they are.

| Variant       | For                                                    |
| ------------- | ------------------------------------------------------ |
| `full-width`  | images as wide as the screen or their column (default) |
| `constrained` | images up to their own width                           |
| `densities`   | small fixed-size images: logos, avatars — 1x and 2x    |

`alt` describes the image; leave it out for a decorative one. The image above
the fold — usually the hero — takes `loading="eager"` and
`fetchPriority="high"`; everything else stays lazy.
