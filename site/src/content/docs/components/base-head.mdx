---

`BaseLayout` renders it from the page's props:

```astro
<BaseLayout
  title="About"
  description="Who we are and how we work."
  image="/og/about.jpg"
  schema={organization()}
/>
```

| It writes                        | From                                                               |
| -------------------------------- | ------------------------------------------------------------------ |
| `<title>` — `About \| Site name` | `title`, and `SITE_NAME`                                           |
| meta description                 | `description`, or `SITE_DESCRIPTION`                               |
| canonical URL                    | the page's path on `SITE_URL`, without `.html` or a trailing slash |
| `noindex`                        | `noindex`, or a route in `NOINDEX_ROUTES`                          |
| Open Graph and Twitter cards     | title, description, `image`, `type`, `lang` or `SITE_LOCALE`       |
| `hreflang` links                 | `alternates`, this page and `x-default` (the `SITE_LOCALE` page)   |
| JSON-LD                          | `schema` — see [SEO](/docs/guides/seo)                             |
| fonts                            | every family in `astro.config.mjs`, the first preloaded            |
| the color scheme                 | `COLOR_MODE`, or the page's pinned `theme`                         |
| the color-mode script            | `COLOR_MODE` is `auto`                                             |
| text scaling                     | always: the OS text size scales the page                           |
| the cascade layer order          | always first                                                       |

Its props are the page's: `title`, `description`, `image`, `type`, `noindex`,
`schema`, `theme`, `lang` and `alternates`, which `BaseLayout` passes
through. A page in another language names itself and its others:

```astro
<BaseLayout title="À propos" lang="fr-FR" alternates={{ "en-US": "/about" }} />
```

`lang` also sets `<html lang>`. Each language's page must list the others —
search engines ignore links that are not returned.
