```astro live stage="stack"
<Input variant="date" label="Start date" />
```

| Variant                               | Type, keyboard and autofill            |
| ------------------------------------- | -------------------------------------- |
| `text`                                | plain text                             |
| `first-name`, `last-name`             | `given-name`, `family-name` autofill   |
| `email`                               | email keyboard, `email` autofill       |
| `phone`                               | phone keypad, `tel` autofill           |
| `date`                                | the native date picker                 |
| `zip-code`                            | numeric keypad, `postal-code` autofill |
| `number`, `search`, `url`, `password` | their native types                     |

The label defaults to the variant's name, `name` to the label's slug.
`required` marks the label and the browser enforces it. `labelHidden` hides the
label visually and keeps it for screen readers.
