---

Press <kbd>Tab</kbd> once on any page of this site to see it. It is invisible
until focused, and moves focus — not only the scroll position — to `<main>`,
in every browser, Safari included.

`BaseLayout` renders it. A custom layout should too, with a `main` (or the
`target` you set) that it can reach.
