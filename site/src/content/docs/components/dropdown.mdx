```astro live
<Dropdown label="Resources">
  <Paragraph><a href="/docs">Documentation</a></Paragraph>
  <Paragraph><a href="/docs/guides/agent-skills">Agent skills</a></Paragraph>
</Dropdown>
```

A button and a native popover, so it opens without JavaScript. Escape or a
click outside closes it, Escape returns focus to the button, and tabbing past
its last link closes it too. Its links stay in the Tab order: it is
navigation, not a menu, so there are no arrow keys. The panel opens under the
button and flips above it, or to its other side, when there is no room on
the screen.

## In a nav

`variant="menu"` is for a dropdown in `Nav`. Below the `medium` breakpoint it
opens in the flow of the mobile menu, pushing the links under it down: there
it is a plain disclosure rather than a popover, which would float over the
menu. From `medium` up it floats like the default, toward the middle of the
page.

```astro
<li>
  <Dropdown variant="menu" label="Design system">
    <ul class="nav_sub">
      <NavLink href="/style-guide">Style Guide</NavLink>
      <NavLink href="/components">Components</NavLink>
    </ul>
  </Dropdown>
</li>
```

`variant="mega"` opens in the mobile menu the same way, and from `medium` up
hangs from the nav's bottom edge across its full width, its content as wide
as the page — room for columns of links:

```astro
<li>
  <Dropdown variant="mega" label="Products">
    <Row>
      <Col span={4}>…</Col>
      <Col span={4}>…</Col>
      <Col span={4}>…</Col>
    </Row>
  </Dropdown>
</li>
```
