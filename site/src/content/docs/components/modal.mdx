```astro live
  </ContentWrapper>
</Modal>
```

It is a native `<dialog>`: focus moves into it and stays there, the page
behind is inert, and Escape closes it. When it closes, focus returns to what
opened it.

Three ways to open one:

- a button with `data-modal-open="<id>"`,
- a link to `#<id>`,
- a URL with `?modal=<id>` — a modal you can link to from an email.
