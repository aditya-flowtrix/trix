## Usage

```astro live stage="block"
<Grid medium={3}>
  <Card
    heading="Default"
    text="Heading, text and a button."
    buttonLabel="Read more"
    buttonHref="/docs"
  />
  <Card
    variant="cover"
    heading="Cover"
    text="The image fills the card behind the text."
    buttonLabel="Read more"
    buttonHref="/docs"
    image={background}
  />
  <Card
    variant="stacked"
    heading="Stacked"
    text="The image sits above the text."
    buttonLabel="Read more"
    buttonHref="/docs"
    image={background}
  />
</Grid>
```

A card is an `<article>`. `heading`, `eyebrow` and `text` accept inline
markup. A card with a button is clickable anywhere: the button's target covers
the card, while other links inside stay on top of it. Its name is its label
then the heading — "Read more: Stacked" — so a page of "Read more" links can
be told apart in a screen reader's list. With `buttonHref` the button is a
link; without it, a `<button>`. A card with neither content nor an image
renders nothing.

A card image loads lazily. One above the fold takes `imageLoading="eager"`,
or `imageFetchPriority="high"` when it is the largest thing there.

A cover card's overlay tints its image toward the card's theme, so the text
reads in light and dark mode; `theme="dark"` keeps it dark in both.
`theme="invert"` sets a card apart from the section around it.
