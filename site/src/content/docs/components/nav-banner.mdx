## Usage

```astro live stage="block"
<NavBanner href="/docs"
  >New: the Trix docs, with every component live. Read more</NavBanner
>
```

Put it in `BaseLayout`, just before `<Nav />`: it scrolls away with the page
while the bar stays. With `href` the whole banner is the link; without one it
is plain text. It takes the `brand` theme's colours, so its contrast is
checked with the rest of the theme.
