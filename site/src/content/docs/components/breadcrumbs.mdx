```astro live
<Breadcrumbs
  items={[
    { label: "Home", href: "/" },
    { label: "Docs", href: "/docs" },
    { label: "Breadcrumbs" },
  ]}
  schema={false}
/>
```

The last item is the current page and needs no `href`. By default it also
writes a `BreadcrumbList` in JSON-LD, which search engines show in place of
the URL in results. `schema={false}` turns that off — as above, since this
page has its own.
