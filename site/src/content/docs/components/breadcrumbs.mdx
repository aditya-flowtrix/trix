```astro live
<Breadcrumbs
  items={[
    { label: "Home", href: "/" },
    { label: "Docs", href: "/docs" },
    { label: "Breadcrumbs" },
  ]}
  schema={false}
/>
```

The last item is the current page. It stays a link, to its own URL unless
you give it an `href`, marked `aria-current="page"`, so the trail reads the
same all the way along. An item between without an `href` is plain text.
By default the trail also
writes a `BreadcrumbList` in JSON-LD, which search engines show in place of
the URL in results. `schema={false}` turns that off — as above, since this
page has its own.
