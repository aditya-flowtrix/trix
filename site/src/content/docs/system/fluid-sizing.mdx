---
title: Fluid sizing
description: Every size is two numbers — phone and desktop — and scales smoothly between them, and with the reader's font size.
order: 3
---

A fluid token is a pair, in px, the way a designer measures it:

```css
--space-7-min: 32; /* at a 320px screen — Figma's Mobile mode */
--space-7-max: 40; /* at a 1440px screen — Figma's Desktop mode */
```

`npm run tokens` turns the pair into one `clamp()`:

```css
--space-7: clamp(2rem, 1.857rem + 0.714vw, 2.5rem);
```

Below 320px it holds at 32px, above 1440px at 40px, and between them it grows
in a straight line. There are no jumps at breakpoints: a heading is the right
size at 900px without anyone having designed 900px.

## Why rem

The clamp is written in `rem`, not `px`. When a visitor sets a larger default
font size, every size scales with it — type, spacing, radius, the grid's
margin and gutter — exactly like browser zoom. A site sized in `px` ignores the
setting; WCAG 1.4.4 asks that it doesn't.

## What is fluid

| Fluid                                     | Fixed                                               |
| ----------------------------------------- | --------------------------------------------------- |
| font sizes (every text style)             | font weights, line heights, letter spacing (ratios) |
| `--space-1` … `--space-12`, section sizes | radius, border width                                |
| `--site-margin`, `--site-gutter`          | breakpoints, max widths                             |

## Breakpoints still exist

For layout changes — columns stacking, a menu collapsing — Trix has three
breakpoints, mobile-first:

| Name     | From            | Webflow's        |
| -------- | --------------- | ---------------- |
| `small`  | `30rem` (480px) | mobile landscape |
| `medium` | `48rem` (768px) | tablet           |
| `large`  | `62rem` (992px) | desktop          |

A media query cannot read a custom property, so components write the values
literally — `@media (width >= 48rem)` — and `npm run check` fails on any other
value. `Grid`'s and `Col`'s `small`, `medium` and `large` props, and the
`span-{breakpoint}-N` classes, use the same three.

## Changing the range

`--viewport-min` and `--viewport-max` set the two screen widths the pairs
describe. Change them only with the designer: they are the widths of the
Figma frames.
