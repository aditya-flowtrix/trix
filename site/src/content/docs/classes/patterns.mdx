Patterns are classes many components use together: the container a `Section`
renders, the margins `.heading` and `.text` share, the flex layouts. They sit
in the `patterns` layer — below components, so a component can adjust one
without fighting it.

You rarely write a pattern class yourself; components apply them. They are
listed here so you know what a component's markup is made of. This list is read
from `patterns.css` when the site builds.
